YANG SAYA BUTUHKAN SEKARANG (FOKUS NON-KODE):
Tolong jabarkan aspek-aspek berikut dalam Bahasa Indonesia yang formal dan ilmiah agar bisa langsung saya adaptasi ke dalam dokumen Bab 3 (Analisis) dan Bab 4 (Perancangan) laporan PKL saya:

A. Analisis Masalah & Solusi (Background & Justification): 
Jelaskan mengapa kombinasi Golang (Goroutines) dan WebSockets adalah solusi ilmiah yang paling tepat untuk mengatasi masalah "dashboard fatigue" dan keterlambatan respon (SLA) tim NOC, jika dibandingkan dengan metode HTTP REST API Polling biasa. Fokus pada efisiensi bandwidth, beban kerja server (CPU/RAM), dan kecepatan respons.

B. Alur Kerja Sistem (Workflow / Data Flow):
Gambarkan penjelasan naratif atau langkah-langkah logis jalannya sistem (dimulai dari inisialisasi koneksi WebSocket dari React, proses Ping berkala oleh Goroutines di Go, hingga data termutakhir merubah warna indikator di dashboard React).

C. Rancangan Struktur Data (JSON Schema):
Buatlah rancangan format data JSON ideal yang dikirim dari Backend Go ke Frontend React via WebSocket untuk merepresentasikan daftar perangkat beserta status hasil ping-nya.
