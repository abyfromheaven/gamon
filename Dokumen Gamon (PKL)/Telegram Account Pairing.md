# Product Requirements Document (PRD)<br/><br/># Feature: Telegram Account Pairing<br/><br/>---<br/><br/>## 1. Informasi Dokumen<br/><br/>| Item | Keterangan |<br/>|------|------------|<br/>| Modul | Telegram Integration |<br/>| Fitur | Telegram Account Pairing |<br/>| Versi | 1.0 |<br/>| Status | Draft |<br/><br/>---<br/><br/># 2. Pendahuluan<br/><br/>## 2.1 Latar Belakang<br/><br/>GAMON menyediakan fitur Telegram Notification untuk mengirimkan informasi gangguan perangkat secara real-time kepada administrator.<br/><br/>Namun, secara bawaan Bot Telegram dapat diakses oleh siapa saja yang mengetahui username bot tersebut. Tanpa adanya mekanisme otorisasi, setiap pengguna Telegram berpotensi berinteraksi dengan bot walaupun sebenarnya tidak memiliki hak untuk menerima notifikasi dari sistem.<br/><br/>Oleh karena itu diperlukan mekanisme **Telegram Account Pairing** yang bertujuan menghubungkan akun Telegram milik administrator dengan akun GAMON secara aman sehingga hanya akun yang telah terotorisasi yang dapat menerima notifikasi.<br/><br/>---<br/><br/>## 2.2 Tujuan<br/><br/>Fitur Telegram Account Pairing bertujuan untuk:<br/><br/>- Menghubungkan akun Telegram administrator dengan akun GAMON.<br/>- Memastikan hanya pengguna yang berwenang menerima notifikasi.<br/>- Menghilangkan kebutuhan memasukkan Chat ID secara manual.<br/>- Meningkatkan keamanan proses integrasi Telegram.<br/><br/>---<br/><br/># 3. Ruang Lingkup<br/><br/>### Termasuk<br/><br/>- Generate Pairing Token<br/>- Validasi Pairing Token<br/>- Penyimpanan Chat ID<br/>- Status Pairing<br/>- Disconnect Telegram<br/><br/>### Tidak Termasuk<br/><br/>- Login menggunakan Telegram<br/>- OTP Telegram<br/>- Telegram Mini App<br/>- Multi-Factor Authentication (MFA)<br/><br/>---<br/><br/># 4. Aktor<br/><br/>### Primary User<br/><br/>Administrator<br/><br/>### Secondary System<br/><br/>- Telegram Bot<br/>- Telegram Bot API<br/><br/>---<br/><br/># 5. Konsep Sistem<br/><br/>Telegram Account Pairing menggunakan mekanisme **One-Time Pairing Token**.<br/><br/>Administrator terlebih dahulu membuat Pairing Token melalui aplikasi GAMON.<br/><br/>Token tersebut kemudian dikirimkan ke Bot Telegram menggunakan perintah `/pair`.<br/><br/>Bot akan meneruskan Token beserta Chat ID ke server GAMON untuk dilakukan validasi.<br/><br/>Apabila Token valid, maka Chat ID Telegram akan dihubungkan dengan akun administrator yang sedang login.<br/><br/>---<br/><br/># 6. Arsitektur Sistem<br/><br/>```text<br/>Administrator<br/>      │<br/>      ▼<br/>Website GAMON<br/>      │<br/>Generate Pairing Token<br/>      │<br/>      ▼<br/>Pairing Database<br/>      │<br/>      ▼<br/>Administrator membuka Telegram Bot<br/>      │<br/>      ▼<br/>/pair &lt;token&gt;<br/>      │<br/>      ▼<br/>Telegram Bot<br/>      │<br/>      ▼<br/>Backend GAMON<br/>      │<br/>      ▼<br/>Validasi Token<br/>      │<br/>      ▼<br/>Simpan Chat ID<br/>      │<br/>      ▼<br/>Telegram Connected<br/>```<br/><br/>---<br/><br/># 7. Alur Pairing<br/><br/>## Langkah 1<br/><br/>Administrator membuka menu<br/><br/>Settings → Telegram Integration<br/><br/>---<br/><br/>## Langkah 2<br/><br/>Administrator menekan tombol<br/><br/>Connect Telegram<br/><br/>---<br/><br/>## Langkah 3<br/><br/>Backend membuat Pairing Token secara acak.<br/><br/>Contoh:<br/><br/>```<br/>GMN-8X9A-KP12<br/>```<br/><br/>Status awal:<br/><br/>```<br/>Pending<br/>```<br/><br/>---<br/><br/>## Langkah 4<br/><br/>Administrator membuka Bot Telegram.<br/><br/>Kemudian menjalankan perintah<br/><br/>```<br/>/pair GMN-8X9A-KP12<br/>```<br/><br/>---<br/><br/>## Langkah 5<br/><br/>Bot memperoleh informasi:<br/><br/>- Pairing Token<br/>- Telegram Chat ID<br/><br/>Kemudian mengirimkannya ke Backend GAMON.<br/><br/>---<br/><br/>## Langkah 6<br/><br/>Backend melakukan validasi.<br/><br/>Jika:<br/><br/>- Token ditemukan<br/>- Token belum digunakan<br/>- Token belum kedaluwarsa<br/><br/>Maka proses pairing dinyatakan berhasil.<br/><br/>---<br/><br/>## Langkah 7<br/><br/>Backend menyimpan:<br/><br/>- Chat ID<br/>- User ID<br/>- Pairing Time<br/><br/>Status berubah menjadi<br/><br/>```<br/>Connected<br/>```<br/><br/>---<br/><br/># 8. Pairing Token<br/><br/>Pairing Token memiliki karakteristik berikut.<br/><br/>| Properti | Nilai |<br/>|----------|-------|<br/>| Random | Ya |<br/>| One Time Use | Ya |<br/>| Expired | Ya |<br/>| Dapat digunakan ulang | Tidak |<br/><br/>---<br/><br/># 9. Validasi Pairing<br/><br/>Backend melakukan pemeriksaan sebagai berikut.<br/><br/>### Rule 1<br/><br/>Token harus ada.<br/><br/>---<br/><br/>### Rule 2<br/><br/>Token belum pernah digunakan.<br/><br/>---<br/><br/>### Rule 3<br/><br/>Token belum kedaluwarsa.<br/><br/>---<br/><br/>### Rule 4<br/><br/>Token masih berstatus Pending.<br/><br/>---<br/><br/>Apabila seluruh validasi berhasil maka Pairing berhasil dilakukan.<br/><br/>---<br/><br/># 10. Status Pairing<br/><br/>| Status | Keterangan |<br/>|---------|------------|<br/>| Pending | Menunggu proses pairing |<br/>| Connected | Telegram berhasil terhubung |<br/>| Expired | Token telah kedaluwarsa |<br/>| Failed | Pairing gagal |<br/>| Disconnected | Hubungan Telegram diputus |<br/><br/>---<br/><br/># 11. Masa Berlaku Token<br/><br/>Token Pairing memiliki masa berlaku.<br/><br/>Contoh:<br/><br/>- Berlaku selama 5 menit.<br/>- Setelah melewati batas waktu token otomatis menjadi Expired.<br/><br/>Token yang telah Expired tidak dapat digunakan kembali.<br/><br/>---<br/><br/># 12. Disconnect Telegram<br/><br/>Administrator dapat memutuskan koneksi Telegram melalui halaman Settings.<br/><br/>Saat proses Disconnect dilakukan:<br/><br/>- Chat ID dihapus dari akun.<br/>- Status berubah menjadi Disconnected.<br/>- Sistem tidak lagi mengirimkan notifikasi Telegram kepada akun tersebut.<br/><br/>---<br/><br/># 13. Functional Requirements<br/><br/>### FR-01<br/><br/>Sistem mampu menghasilkan Pairing Token.<br/><br/>---<br/><br/>### FR-02<br/><br/>Sistem mampu memvalidasi Pairing Token.<br/><br/>---<br/><br/>### FR-03<br/><br/>Sistem mampu menyimpan Chat ID Telegram.<br/><br/>---<br/><br/>### FR-04<br/><br/>Sistem mampu menghubungkan akun Telegram dengan akun administrator.<br/><br/>---<br/><br/>### FR-05<br/><br/>Sistem mampu memutus koneksi Telegram.<br/><br/>---<br/><br/>### FR-06<br/><br/>Sistem menolak Pairing Token yang tidak valid.<br/><br/>---<br/><br/>### FR-07<br/><br/>Sistem menolak Pairing Token yang telah digunakan.<br/><br/>---<br/><br/>### FR-08<br/><br/>Sistem menolak Pairing Token yang telah kedaluwarsa.<br/><br/>---<br/><br/># 14. Non-Functional Requirements<br/><br/>- Pairing harus selesai dalam waktu singkat.<br/>- Token harus dibuat secara acak.<br/>- Token hanya dapat digunakan satu kali.<br/>- Pairing tidak memerlukan input Chat ID secara manual.<br/>- Integrasi mudah digunakan oleh administrator.<br/><br/>---<br/><br/># 15. Acceptance Criteria<br/><br/>| ID | Acceptance Criteria |<br/>|----|---------------------|<br/>| AC-01 | Administrator dapat membuat Pairing Token. |<br/>| AC-02 | Administrator dapat menghubungkan Telegram menggunakan Token. |<br/>| AC-03 | Pairing gagal apabila Token salah. |<br/>| AC-04 | Pairing gagal apabila Token telah kedaluwarsa. |<br/>| AC-05 | Pairing gagal apabila Token telah digunakan. |<br/>| AC-06 | Chat ID berhasil tersimpan setelah Pairing berhasil. |<br/>| AC-07 | Telegram dapat diputuskan melalui halaman Settings. |<br/><br/>---<br/><br/># 16. Future Enhancement<br/><br/>Pengembangan berikutnya dapat mencakup:<br/><br/>- Multiple Telegram Account<br/>- Multiple Group Telegram<br/>- QR Code Pairing<br/>- Pairing Confirmation<br/>- Pairing History<br/>- Device Management<br/>- Pairing Audit Log<br/>- Notification Permission Management<br/><br/>---<br/><br/># 17. Kesimpulan<br/><br/>Telegram Account Pairing merupakan mekanisme otorisasi yang digunakan untuk menghubungkan akun Telegram administrator dengan akun GAMON menggunakan Pairing Token yang bersifat sementara dan hanya dapat digunakan satu kali.<br/><br/>Melalui pendekatan ini, proses integrasi menjadi lebih aman, praktis, dan tidak memerlukan konfigurasi Chat ID secara manual. Selain meningkatkan kemudahan penggunaan, mekanisme Pairing juga memastikan bahwa hanya akun Telegram yang telah terotorisasi yang dapat menerima notifikasi dari sistem GAMON.
