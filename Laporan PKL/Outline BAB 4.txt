4.8 Perancangan Sistem
Prinsip: Bagian ini menjelaskan "Desain Sistem". Bukan menjelaskan implementasi, bukan screenshot aplikasi, dan bukan source code. Jadi setiap bagian harus menjawab: "Bagaimana sistem ini dirancang sebelum dibuat?"

0. Pengantar Perancangan

1. Arsitektur Sistem
Yang dibahas:
- Browser
- Gambaran umum arsitektur client-server
- Frontend React
- Backend Go
- SQLite
- REST API
- WebSocket
- ICMP
- Telegram Bot API
Lalu diberi diagram arsitektur

Kemudian dijelaskan:
- Siapa berkomunikasi dengan siapa
- Data mengalir kemana
- Fungsi masing-masing komponen

Jangan:
- Menjelaskan endpoint
- Menjelaskan goroutine
- Menjelaskan kode golang
karena itu bagian dari implementasi, bukan desain / perancangan sistem.
